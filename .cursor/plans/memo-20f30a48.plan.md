# 마크다운 편집·프리뷰 도입 계획

## 단계 1: 의존성 및 환경 준비

- `package.json`에 `@uiw/react-md-editor`와 `@uiw/react-markdown-preview`를 추가하고 필요 CSS를 `globals.css` 등 클라이언트 엔트리에서 로드합니다.
- Next SSR 이슈를 피하기 위해 dynamic import 전략을 설계합니다.

## 단계 2: 공용 마크다운 에디터/프리뷰 컴포넌트 작성

- `src/components/MarkdownEditor.tsx`와 `src/components/MarkdownPreview.tsx`를 만들고 `next/dynamic`으로 `MDEditor`/`MarkdownPreview`를 불러오며 로딩 상태를 처리합니다.
- 에디터는 `preview="live"` 기본값으로 편집과 실시간 미리보기를 동시에 노출하도록 구성합니다.

## 단계 3: 메모 작성/편집 폼 교체

- `src/components/MemoForm.tsx`에서 기존 `textarea`를 Markdown 에디터로 교체하고 값/검증 로직을 유지합니다.
- 태그 등 다른 필드는 그대로 두되, 에디터 높이·레이블·접근성 텍스트를 조정합니다.

## 단계 4: 메모 프리뷰/뷰어에 마크다운 렌더링 적용

- `src/components/MemoViewerModal.tsx`와 `src/components/MemoItem.tsx`에서 공용 프리뷰 컴포넌트를 사용해 내용을 마크다운으로 렌더링하고, 카드에서는 `line-clamp`나 gradient로 요약 표시를 유지합니다.
- 스타일을 Tailwind 톤과 조화롭게 정리하고 전체 UI를 검증합니다.
